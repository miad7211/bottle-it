# Bottle It 🫙

A Chrome extension that turns impulse purchases into collectible bottles. Bottle the urge, wait it out, decide with a clear head.

## What it does
- Right-click any product page → **Bottle it 🫙**
- Set a cooling-off period (3 / 5 / 7 / 14 days, or custom)
- Item lives in your jar as a photographic bottle, drifting gently
- Timer ends → bottle glows → you decide: buy it, toss it, or lock it again
- More bottle types quietly appear in your jar as you complete more cool-offs

## Run locally
1. `npm install`
2. Open `chrome://extensions/` in Chrome
3. Toggle "Developer mode" (top right)
4. Click "Load unpacked", pick the `extension/` folder
5. Pin the Bottle It icon to your toolbar

## Test
