# Bottle It Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Chrome extension that lets users lock impulse purchases into a "jar" for a chosen cooling-off period, earning collectible bottles as a positive-reinforcement gamification mechanic.

**Architecture:** Manifest V3 Chrome extension only — no backend, no website hosting, no auth. The "companion website" is a full-page extension URL (`chrome-extension://<id>/jar/jar.html`) that reads/writes `chrome.storage.sync`. All UI is vanilla HTML/CSS/JS. Pure logic (bottle assignment, timer math) lives in plain ES modules and is unit-tested with vitest.

**Visual direction:** "Soft Pastel Aquarium" — bottles drift on free-flowing arcs inside a jar (no grid), photographic AI-generated bottles on pastel backdrops, hidden progression (more bottle types appear over time, no level UI). Full design rules in `docs/design/principles.md` — read it before writing any UI code.

**Tech Stack:** HTML, CSS, vanilla JS (ES modules), Chrome Extension Manifest V3, `chrome.storage.sync`, `chrome.contextMenus`, vitest (for pure-logic tests only).

## Data Model (lock this in your head)

A single locked item:

```js
{
  id: "lock_1746635400000_a3f",     // unique id, generated at lock time
  productName: "Sephora Holiday Eyeshadow Palette",
  productUrl: "https://sephora.com/...",
  imageUrl: "https://...",           // og:image scraped from page
  price: 60,                         // user-entered, optional
  currency: "USD",                   // default user locale
  note: "saw on 小红书, too tempting",  // user-entered
  lockedAt: 1746635400000,           // Date.now() at lock time
  unlockAt: 1747240200000,           // lockedAt + duration
  durationDays: 7,                   // 3 | 5 | 7 | 14 | custom
  bottleType: "champagne",           // assigned at lock time, stays forever
  position: { x: 0.42, y: 0.71 },   // ratio 0..1 of jar bounds, fixed at lock time
  animDelay: { x: -3.2, y: 1.7, r: 0.4 }, // animation-delay in seconds for each axis
  status: "locked"                   // "locked" | "opened-bought" | "opened-tossed" | "shattered"
}
```

All items live as an array under one storage key: `bottleit_items`.

**Why position + animDelay are persisted:** if we generated them at render time, bottles would teleport every time you open the jar. Persisting at lock time means each bottle has a *consistent personality* — its drift pattern is uniquely its own forever.

User stats (derived from items, not stored separately):
- Total bottles in jar (status: locked + ready + opened)
- Money saved (sum of `price` for status: opened-and-tossed)
- Money spent intentionally (sum of `price` for status: opened-and-bought)

```js
export const BOTTLE_TYPES = {
  cola:        { emoji: '🥤', label: 'Cola' },
  soda:        { emoji: '🧃', label: 'Soda' },
  beer:        { emoji: '🍺', label: 'Beer' },
  bubble_tea:  { emoji: '🧋', label: 'Bubble Tea' },
  wine_red:    { emoji: '🍷', label: 'Red Wine' },
  wine_white:  { emoji: '🥂', label: 'White Wine' },
  champagne:   { emoji: '🍾', label: 'Champagne' },
  sake:        { emoji: '🍶', label: 'Sake' },
  whiskey:     { emoji: '🥃', label: 'Whiskey' },
};

const PROGRESSION = [
  { unlocksAt: 0,  bottles: ['cola', 'soda'] },
  { unlocksAt: 2,  bottles: ['beer', 'bubble_tea'] },
  { unlocksAt: 5,  bottles: ['wine_red', 'wine_white'] },
  { unlocksAt: 10, bottles: ['champagne', 'sake'] },
  { unlocksAt: 20, bottles: ['whiskey'] },
];

export function getUnlockedBottles(successfulUnlocksCount) {
  return PROGRESSION
    .filter(t => successfulUnlocksCount >= t.unlocksAt)
    .flatMap(t => t.bottles);
}

export function pickBottleType(durationDays, successfulUnlocksCount) {
  const pool = getUnlockedBottles(successfulUnlocksCount);
  // Bias longer locks toward later (rarer) items in the pool.
  const bias = Math.min(durationDays / 14, 1); // 0..1
  const r = Math.random();
  // weight: higher bias pushes pick toward end of pool
  const idx = Math.floor((r * (1 - bias) + bias) * pool.length) % pool.length;
  return pool[idx];
}

export function countSuccessfulUnlocks(items) {
  return items.filter(i => i.status === 'opened-bought' || i.status === 'opened-tossed').length;
}

export function isFirstAppearance(bottleType, existingItems) {
  return !existingItems.some(i => i.bottleType === bottleType);
}
```

```js
const DAY_MS = 24 * 60 * 60 * 1000;
const HOUR_MS = 60 * 60 * 1000;
const MIN_MS = 60 * 1000;

export function computeUnlockAt(lockedAt, durationDays) {
  return lockedAt + durationDays * DAY_MS;
}

export function isReady(now, unlockAt) {
  return now >= unlockAt;
}

export function formatRemaining(now, unlockAt) {
  const ms = unlockAt - now;
  if (ms <= 0) return 'ready';
  if (ms >= DAY_MS) {
    const days = Math.floor(ms / DAY_MS);
    const hours = Math.floor((ms % DAY_MS) / HOUR_MS);
    return `${days}d ${hours}h`;
  }
  const hours = Math.floor(ms / HOUR_MS);
  const mins = Math.floor((ms % HOUR_MS) / MIN_MS);
  return `${hours}h ${mins}m`;
}
```

```js
const KEY = 'bottleit_items';

export async function getAllItems() {
  const result = await chrome.storage.sync.get(KEY);
  return result[KEY] || [];
}

export async function saveItem(item) {
  const items = await getAllItems();
  items.push(item);
  await chrome.storage.sync.set({ [KEY]: items });
}

export async function updateItem(id, patch) {
  const items = await getAllItems();
  const idx = items.findIndex(i => i.id === id);
  if (idx === -1) throw new Error(`Item ${id} not found`);
  items[idx] = { ...items[idx], ...patch };
  await chrome.storage.sync.set({ [KEY]: items });
}

export async function removeItem(id) {
  const items = await getAllItems();
  const filtered = items.filter(i => i.id !== id);
  await chrome.storage.sync.set({ [KEY]: filtered });
}

export function generateId() {
  return `lock_${Date.now()}_${Math.random().toString(36).slice(2, 5)}`;
}
```

```js
import { getAllItems } from '../lib/storage.js';
import { BOTTLE_TYPES } from '../lib/bottles.js';
import { isReady, formatRemaining } from '../lib/timer.js';

const $bounds = document.getElementById('jar-bounds');
const $empty = document.getElementById('empty-state');
const $hint = document.getElementById('hint-bar');
const $toast = document.getElementById('toast');

async function render() {
  const items = await getAllItems();
  const visibleItems = items.filter(i => i.status !== 'shattered');

  if (visibleItems.length === 0) {
    $empty.style.display = 'block';
    $bounds.style.display = 'none';
    $hint.textContent = '';
    updateStats(items);
    return;
  }
  $empty.style.display = 'none';
  $bounds.style.display = 'block';
  $hint.textContent = 'hover any bottle for details · click to open';

  const now = Date.now();
  $bounds.innerHTML = visibleItems.map(item => {
    const bottle = BOTTLE_TYPES[item.bottleType];
    const ready = isReady(now, item.unlockAt) && item.status === 'locked';
    const stateClass = ready ? 'ready' : item.status;
    const countdown = ready ? '✨ ready!' : formatRemaining(now, item.unlockAt);
    const px = (item.position?.x ?? 0.5) * 100;
    const py = (item.position?.y ?? 0.5) * 100;
    const dx = item.animDelay?.x ?? 0;
    const dy = item.animDelay?.y ?? 0;
    const dr = item.animDelay?.r ?? 0;
    const style = [
      `left: calc(${px}% - 48px)`,
      `top: calc(${py}% - 48px)`,
      `--delay-x: ${dx}s`,
      `--delay-y: ${dy}s`,
      `--delay-r: ${dr}s`,
      `--dur-x: ${10 + (item.id.charCodeAt(5) % 6)}s`,
      `--dur-y: ${7 + (item.id.charCodeAt(6) % 5)}s`,
      `--dur-r: ${5 + (item.id.charCodeAt(7) % 4)}s`,
    ].join('; ');
    return `
      <div class="bottle ${stateClass}" data-id="${item.id}" style="${style}">
        <span class="emoji">${bottle.emoji}</span>
        <div class="tooltip">${escapeHtml(item.productName)} · ${countdown}</div>
      </div>
    `;
  }).join('');

  $bounds.querySelectorAll('.bottle').forEach(el => {
    el.addEventListener('click', () => {
      const id = el.dataset.id;
      chrome.tabs.create({ url: chrome.runtime.getURL(`unlock/unlock.html?id=${id}`) });
    });
  });

  updateStats(items);
  maybeShowFirstAppearanceToast(items);
}

function updateStats(items) {
  const bottles = items.filter(i => i.status !== 'shattered').length;
  const saved = items.filter(i => i.status === 'opened-tossed').reduce((s, i) => s + (i.price || 0), 0);
  const bought = items.filter(i => i.status === 'opened-bought').reduce((s, i) => s + (i.price || 0), 0);
  document.getElementById('stat-bottles').textContent = bottles;
  document.getElementById('stat-saved').textContent = `$${saved}`;
  document.getElementById('stat-bought').textContent = `$${bought}`;
}

async function maybeShowFirstAppearanceToast(items) {
  const SEEN_KEY = 'bottleit_seen_types';
  const { [SEEN_KEY]: seen = [] } = await chrome.storage.sync.get(SEEN_KEY);
  const present = new Set(items.filter(i => i.status !== 'shattered').map(i => i.bottleType));
  const newTypes = [...present].filter(t => !seen.includes(t));
  if (newTypes.length === 0) return;
  $toast.hidden = false;
  $toast.textContent = 'a new kind of bottle has appeared in your jar ✨';
  setTimeout(() => { $toast.hidden = true; }, 4000);
  await chrome.storage.sync.set({ [SEEN_KEY]: [...seen, ...newTypes] });
}

function escapeHtml(s) {
  return String(s).replace(/[&<>"']/g, c => ({'&':'&amp;','<':'&lt;','>':'&gt;','"':'&quot;',"'":'&#39;'}[c]));
}

render();
setInterval(render, 30 * 1000);
```

```js
import { saveItem, generateId, getAllItems } from '../lib/storage.js';
import { pickBottleType, countSuccessfulUnlocks } from '../lib/bottles.js';
import { computeUnlockAt } from '../lib/timer.js';

const params = new URLSearchParams(window.location.search);
const sourceTabId = parseInt(params.get('tabId'), 10);

const $name = document.getElementById('product-name');
const $url = document.getElementById('product-url');
const $img = document.getElementById('preview-img');
const $price = document.getElementById('price');
const $note = document.getElementById('note');
const $custom = document.getElementById('custom-days');
const $lockBtn = document.getElementById('lock-btn');
const $cancelBtn = document.getElementById('cancel-btn');

async function prefillFromTab() {
  if (!Number.isFinite(sourceTabId)) return;
  try {
    const tab = await chrome.tabs.get(sourceTabId);
    $url.value = tab.url || '';
    $name.value = tab.title || '';

    const [{ result } = {}] = await chrome.scripting.executeScript({
      target: { tabId: sourceTabId },
      func: () => {
        const og = document.querySelector('meta[property="og:image"]');
        return og?.content || '';
      },
    }).catch(() => [{}]);
    if (result) $img.src = result;
  } catch (e) {
    console.warn('prefill failed:', e);
  }
}

function getDurationDays() {
  const checked = document.querySelector('input[name="duration"]:checked');
  if (!checked) return 7;
  if (checked.value === 'custom') {
    const n = parseInt($custom.value, 10);
    return Number.isFinite(n) && n > 0 ? n : 7;
  }
  return parseInt(checked.value, 10);
}

// Random position within jar bounds, biased away from center clustering.
function randomPosition() {
  return {
    x: 0.1 + Math.random() * 0.8,
    y: 0.15 + Math.random() * 0.7,
  };
}

// Random per-axis animation delays (negative ok — desyncs the loops).
function randomAnimDelays() {
  return {
    x: -Math.random() * 12,
    y: -Math.random() * 9,
    r: -Math.random() * 7,
  };
}

$lockBtn.addEventListener('click', async () => {
  const productName = $name.value.trim();
  if (!productName) {
    $name.focus();
    return;
  }
  const durationDays = getDurationDays();
  const lockedAt = Date.now();
  const allItems = await getAllItems();
  const successfulUnlocks = countSuccessfulUnlocks(allItems);
  const item = {
    id: generateId(),
    productName,
    productUrl: $url.value.trim(),
    imageUrl: $img.src || '',
    price: parseFloat($price.value) || 0,
    currency: 'USD',
    note: $note.value.trim(),
    lockedAt,
    unlockAt: computeUnlockAt(lockedAt, durationDays),
    durationDays,
    bottleType: pickBottleType(durationDays, successfulUnlocks),
    position: randomPosition(),
    animDelay: randomAnimDelays(),
    status: 'locked',
  };
  await saveItem(item);
  window.location.href = chrome.runtime.getURL('jar/jar.html');
});

$cancelBtn.addEventListener('click', () => window.close());
```

- [ ] **Step 3: Create `unlock.js`**

```js
import { getAllItems, updateItem, removeItem } from '../lib/storage.js';
import { BOTTLE_TYPES } from '../lib/bottles.js';
import { isReady, computeUnlockAt } from '../lib/timer.js';

const params = new URLSearchParams(window.location.search);
const itemId = params.get('id');

const $emoji = document.getElementById('bottle-emoji');
const $title = document.getElementById('title');
const $img = document.getElementById('item-img');
const $name = document.getElementById('item-name');
const $price = document.getElementById('item-price');
const $note = document.getElementById('note-block');
const $metaLocked = document.getElementById('meta-locked');
const $metaDuration = document.getElementById('meta-duration');
const $buy = document.getElementById('buy-btn');
const $toss = document.getElementById('toss-btn');
const $relock = document.getElementById('relock-btn');
const $earlyWarn = document.getElementById('early-warning');
const $shatter = document.getElementById('shatter-btn');
const $close = document.getElementById('close-btn');
const $actions = document.querySelector('.actions');

let item;

async function load() {
  const all = await getAllItems();
  item = all.find(i => i.id === itemId);
  if (!item) {
    document.body.innerHTML = '<p style="color:white;text-align:center;padding:40px;">Bottle not found.</p>';
    return;
  }
  const bottle = BOTTLE_TYPES[item.bottleType];
  $emoji.textContent = bottle.emoji;
  $img.src = item.imageUrl || '';
  $name.textContent = item.productName;
  $price.textContent = item.price ? `$${item.price.toFixed(2)}` : '';
  $note.textContent = item.note ? `"${item.note}"` : '';
  $metaLocked.textContent = new Date(item.lockedAt).toLocaleDateString();
  $metaDuration.textContent = item.durationDays;

  const ready = isReady(Date.now(), item.unlockAt);
  if (!ready) {
    $title.textContent = 'Not yet ready';
    $actions.style.display = 'none';
    $earlyWarn.style.display = 'block';
  }
}

$buy.addEventListener('click', async () => {
  await updateItem(item.id, { status: 'opened-bought' });
  if (item.productUrl) chrome.tabs.create({ url: item.productUrl });
  window.close();
});

$toss.addEventListener('click', async () => {
  await updateItem(item.id, { status: 'opened-tossed' });
  window.location.href = chrome.runtime.getURL('jar/jar.html');
});

$relock.addEventListener('click', async () => {
  const now = Date.now();
  await updateItem(item.id, {
    lockedAt: now,
    unlockAt: computeUnlockAt(now, 7),
    durationDays: 7,
    notified: false,
    status: 'locked',
  });
  window.location.href = chrome.runtime.getURL('jar/jar.html');
});

$shatter.addEventListener('click', async () => {
  await removeItem(item.id);
  window.location.href = chrome.runtime.getURL('jar/jar.html');
});

$close.addEventListener('click', () => window.close());

load();
```
